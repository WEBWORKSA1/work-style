# Work.Style

Find your work style, then build your workdays around it. Free assessment, 8 work-style profiles, 6 tools, 10 guides, team reports, contests and reader support.

- **Live (GitHub Pages):** https://webworksa1.github.io/work-style/
- **Domain:** work.style (add a `CNAME` file containing `work.style` once DNS points to GitHub Pages)
- **Stack:** static HTML/CSS/JS generated by `_build/build.py` (Python 3 + `markdown`). No server needed.

## Edit and rebuild
```
pip install markdown
python3 _build/build.py
```
Guides: `_build/guides/*.md` · Archetypes: `_build/styles_data.py` · Payments and site settings: `assets/js/config.js`.

See `PROMPTS.md` for the business case and phase-wise build prompt, and `RESEARCH.md` for the 44-site competitive review.
